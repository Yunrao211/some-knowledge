# 张宇1000题 · 概念积累

做题时反复要回查的东西，单独抽出来放这里。

## 为什么单独建一套

考研数学一的题目里，**卡住人的往往不是思路，是记不起来的公式和用不上手的变形**。教材和教辅把这些散在几百页里，翻一次成本很高。所以这里按「查表」而不是「教程」的粒度组织。

## 文件粒度约定

每一条都按三样写：

| 要素 | 说明 |
|:---|:---|
| **公式** | 本体，写清楚适用形式 |
| **识别标志** | 题目出现什么特征时该想到它 |
| **使用场景** | 什么时候用、和哪些容易混 |

**刻意不写**的两样：

- **不写易错点**——坑要自己踩过才记得住，做了题再回来补
- **不写完整例题解法**——例题在书上，这里只留索引式的提醒
