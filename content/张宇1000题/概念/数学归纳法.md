# 数学归纳法及加强命题

> **预积累文件**。粒度约定：**公式 + 识别标志 + 使用场景**。不写易错点（自己做题积累），不写完整例题解法（例子只到「关键一步」）。
> 变体范围：第一归纳、第二（强）归纳、跳跃归纳、螺旋归纳。不含反向归纳、最小数原理。

---

## 一、通用骨架

证明关于自然数 $n$ 的命题 $P(n)$ 对 $n\ge n_0$ 成立，永远走三步：

| 步 | 做什么                                                                                                                               | 卡点               |
| :- | :----------------------------------------------------------------------------------------------------------------------------------- | :----------------- |
| 1  | **写清 $P(n)$ 到底是什么**（把 $n$ 代进题面，写出一个带 $n$ 的、能判断真假的句子） | 最常失分处。$P(n)$ 写错，后面全废 |                    |
| 2  | **验证起点** $P(n_0)$ 成立                                                                                                   | 纯粹计算           |
| 3  | **归纳步**：把 $P(k)$ 当作**已知条件**用，推出 $P(k+1)$                                                              | 卡点在于不会用假设 |

**第 3 步是要害**：归纳假设是归纳步里**唯一能用的额外信息**。所有归纳法变体、所有加强技巧，本质都在调制「假设里给了你多少东西」。
得到的结论强度 < 需要证明的强度 $\Rightarrow$ 假设不够用 $\Rightarrow$ 走第二节的加强手段。

## 二、四种变体对照

| 变体           | 归纳假设给什么                                                                                                                  | 归纳步证什么                                                                                                            | 识别标志（题面信号）                                              |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------- |
| 第一归纳       | $P(k)$                                                                                                                        | $P(k{+}1)$ | 递推只用到**前一项**；$a_{n+1}$ 只含 $a_n$                                                     |                                                                   |
| 第二（强）归纳 | $P(k),P(k{-}1),\dots,P(n_0)$ 全部                                                                                             | $P(k{+}1)$ | 递推用到**前多项**，或有「$a_{n+1}$ 依赖 $\max/\min$」；拆项式证明（拆成两个已知规模的小情形） |                                                                   |
| 跳跃归纳       | $P(k)\Rightarrow P(k{+}2)$，起点验两个 | 只推进**固定步长** | 式子分奇偶；$a_{n+1}$ 与 $a_{n-1}$ 挂钩（隔一项递推） |                                                                                                                         |                                                                   |
| 螺旋归纳       | 同时假设$A(k)$ 与 $B(k)$                                                                                                    | $B(k{+}1)$ 与 $A(k{+}1)$                                                                                            | 结论是**两条互相引用**的命题；两个数列 $a_n,b_n$ 互相递推 |

标准形式（供对照）：

$$
\underbrace{P(n_0)}_{\text{起点}}\ \wedge\ \underbrace{\big(P(k)\Rightarrow P(k{+}1)\big)}_{\text{归纳步，}\forall k\ge n_0}\quad\Longrightarrow\quad \forall n\ge n_0,\ P(n)
$$

跳跃归纳的归纳步换成 $P(k)\Rightarrow P(k{+}2)$，起点须验 $P(n_0)$ 与 $P(n_0{+}1)$ 两个。
第二归纳的归纳步换成 $\big(P(n_0)\wedge\cdots\wedge P(k)\big)\Rightarrow P(k{+}1)$。

### 微型例子

- **第二归纳**：$a_{n+1}=a_n+a_{n-1}$，证 $a_n\ge 2^{n-1}$。关键一步：不能只用 $a_k$，必须把 $a_k\ge2^{k-1}$ 与 $a_{k-1}\ge 2^{k-2}$ 两条一起代入。
- **跳跃归纳**：证 $x+\dfrac1x\in\mathbb{Z}\Rightarrow x^n+\dfrac1{x^n}\in\mathbb{Z}$。关键一步：递推式为 $S_{n+1}=S_n S_1-S_{n-1}$——含 $S_{n-1}$，故步长 2，起点验 $n=1,2$。
- **螺旋归纳**：$a_{n+1}=2a_n+b_n,\ b_{n+1}=a_n+2b_n$，证「$a_n>0$ 且 $b_n>0$」。关键一步：两条结论互相需要，单证一条断链。

## 三、加强命题（重点）

### 3.1 为什么必须加强

归纳步里能用的已知条件**只有**假设 + 起点。因此：

$$
\text{假设不够强}\ \Longrightarrow\ \text{推不出 } P(k{+}1)\ \Longrightarrow\ \text{必须改成证一个更强的命题 } Q(n)
$$

要求：**$Q(n)\Rightarrow P(n)$（加强后能推出原结论），同时 $Q(n)$ 自己能归纳得下去**。这两条同时满足，加强才成立。

### 3.2 四种加强手段

| 手段                                      | 做法                                         | 信号 / 适用                                        |
| :---------------------------------------- | :------------------------------------------- | :------------------------------------------------- |
| **补第二个命题**                    | 把单一命题改成两条命题$A(n),B(n)$ 一起归纳 | 两条结论相互依赖；只证其一必断链                   |
| **加强为不等式**                    | 改成证$L(n)<a_n<U(n)$（原结论只是单边）    | 归纳步要同时用上界与下界，或推单调需两边           |
| **加参数**                          | 引入参数入假设，凑到归纳步恰好通过           | 题面给的常数不够紧；结论里的界"刚好差一点"         |
| **加强为「对一切 $\le n$ 成立」** | 假设换成$\forall m\le k,\ P(m)$            | 归纳步需要从"某个更早的项"取值（强归纳的直接来源） |

### 3.3 典型形态（微型例子）

1. **加强为不等式**（经典）：证 $\displaystyle\sum_{k=1}^{n}\frac1{k^2}<2$。
   直接归纳会卡住：$S_{k+1}<2+\frac1{(k+1)^2}$，**越过了 2**，假设 $S_k<2$ 白给。
   **关键一步**：加强为 $S_n<2-\dfrac1n$——余项被"预留"下来，
   $\dfrac1n-\dfrac1{n+1}=\dfrac1{n(n+1)}>\dfrac1{(n+1)^2}$，归纳步恰好通过，且 $2-\frac1n<2$ 能推出原结论。

   > 对照：证 $\displaystyle\sum_{k=1}^{n}\frac1{\sqrt k}>\sqrt n$ **不需要**加强——$S_{k+1}>\sqrt k+\frac1{\sqrt{k+1}}$，
   > 而 $\sqrt{k+1}-\sqrt k=\dfrac1{\sqrt{k+1}+\sqrt k}<\dfrac1{\sqrt{k+1}}$，原假设就够。**加强只在假设推不动时才做。**
   >
2. **补第二个命题**：$a_{n+1}=\sqrt{2+a_n}$。要同时证**有界**与**单调**，但假设单一不等式推不出单调。
   **关键一步**：加强为 $1\le a_k<a_{k+1}<2$ 一条链——上界供夹逼、下界供 $a_{n+1}-a_n=\dfrac{2+a_n-a_n^2}{a_{n+1}+a_n}>0$ 的符号判断。一条加强命题同时供给两个结论。
3. **加参数**：证 $1+\frac12+\cdots+\frac1n<1+\ln n$ 型命题，归纳步余量恰好为零时证不动。
   **关键一步**：把结论放宽到 $S_n\le C+\ln n$（$C$ 待定），用 $\ln\big(1+\frac1n\big)\ge\frac{1}{n+1}$ 配平，最后取 $C=1$。
4. **加强为「对一切 $\le n$」**：需要"某个更早的项满足某性质"才能推进（如 $\exists m\le k$ 使某式成立），单点假设 $P(k)$ 不够。
   **关键一步**：假设直接写成 $\forall m\le k,\ P(m)$——这一步等于把第一归纳升格为第二归纳。

### 3.4 加强的边界

**加强过多会反过来证不出**——$Q(n)$ 自己也要能归纳。判据是试 $n$ 的几个小值：
若 $Q$ 对某个小 $n$ 已经假，说明加强越界。经典例：证 $\displaystyle\sum_{k=1}^{n}\frac1{k^2}<2$，加强为 $<2-\frac1n$ 恰好能归纳（余项被保留），而加强为 $<2-c$（$c>0$ 固定）时，因级数实际收敛到 $\pi^2/6\approx1.6449$，取 $c<2-\pi^2/6\approx0.355$ 尚可真、取更大即假。
**操作规则：加强的强度由归纳步能通过的最小需求决定，不是越强越好，而是"刚好够用 + 起点能验"。**

## 四、三个不可放松的前提

| 前提                                        | 放松后             | 失败形态                                             |
| :------------------------------------------ | :----------------- | :--------------------------------------------------- |
| 起点$P(n_0)$ 成立                         | 不验起点           | 命题对全部$n$ 假也能"归纳"下去（经典：所有马同色） |
| 归纳步对**一切** $k\ge n_0$ 成立    | 只对部分$k$ 成立 | 断链，覆盖不到所有$n$                              |
| $n$ 取遍全部 $n\ge n_0$（离散、无上界） | 换成实数区间       | 需改用连续归纳/最值定理，不适用                      |

**与最易混淆对象的差异**：归纳法 vs **最小数原理**（反证式：设反例集非空，取其最小元，由其最小性导出矛盾）——两者逻辑等价，判据是"正着推链"还是"取最小反例"。归纳法 vs **单调有界准则**见第六节（一个证界，一个证极限存在）。

## 五、使用场景分类（按张宇题型分布）

| 题型                | 典型命题形式                                  | 选哪个变体 | 加强的必要性                     |
| :------------------ | :-------------------------------------------- | :--------- | :------------------------------- |
| 证数列不等式        | $a_n<U(n)$；$S_n<U(n)$                    | 第一归纳   | 高频需加强（单边 → 双边界）     |
| 证数列有界 + 单调   | $m\le a_n\le M$                             | 第一归纳   | 高频需加强（两个结论捆成一条链） |
| 证整除 / 恒等式     | $f(n)$ 被 $p$ 整除；$\sum$ 与组合恒等式 | 第一归纳   | 视情形（组合恒等式常需补命题）   |
| 递推含前多项        | $a_{n+1}=f(a_n,a_{n-1})$                    | 第二归纳   | 低（强归纳自带足够假设）         |
| 隔项递推 / 奇偶分列 | $a_{n+1}=f(a_{n-1})$                        | 跳跃归纳   | 低（起点验两个）                 |
| 双数列互相递推      | $a_{n+1},b_{n+1}$ 同时出现                  | 螺旋归纳   | 高（两条缺一不可）               |
| 猜通项后验证        | 已猜$a_n=g(n)$，证其正确                    | 第一归纳   | 低（结论已具体，直接代）         |

## 六、边界：与相邻工具的分工

| 面对的问题                           | 用归纳法           | 用别的                                                   |
| :----------------------------------- | :----------------- | :------------------------------------------------------- |
| 证明「$\forall n$，$a_n<2$」     | ✅ 直接归纳        | —                                                       |
| 证明「$\{a_n\}$ 收敛」（只求存在） | ✗ 不必            | **单调有界准则**：单调 + 有界 $\Rightarrow$ 收敛 |
| 求「$\lim a_n = ?$」               | ✗                 | 单调有界准则证存在 + 递推式取极限解方程                  |
| 求「$a_n = ?$」（通项）            | 只做**验证** | 通项求法见[[数列通项与求和]]（本文件只写边界）                             |
| 证明$\sum a_n$ 收敛/发散           | ✗                 | 比较/比值/积分判别法，见数学分析-常识与公式积累 第十二节                        |
| 需要「取最小反例」更快               | 等价，可换         | 最小数原理（反证式）                                     |

**归纳法与单调有界准则的具体分工**：归纳法**直接给出界的具体值**，但需要先猜到界；单调有界准则**不要求知道极限值**就能断定收敛，代价是必须先证单调。张宇题里两者常串用——归纳法证有界 + 归纳法证单调 $\Rightarrow$ 交单调有界准则得收敛。

> 相关的界与不等式工具见 [[不等式积累]] · [[柯西-施瓦茨不等式]]。
