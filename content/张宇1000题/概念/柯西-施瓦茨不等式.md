# 柯西-施瓦茨不等式

> **预积累文件**。粒度约定：**公式 + 识别标志 + 使用场景**。不写易错点，不写完整例题解法。
> **单独立文的原因**（2026-09-13）：对「$(a_1b_1+a_2b_2)^2\le(a_1^2+a_2^2)(b_1^2+b_2^2)$」和「柯西不等式」「范数不等式」的关系分不清——**它们是同一个不等式的不同写法**，这份文件专门钉死这件事。

---

## 一、四种形式（同一件事）

| # | 名称 | 形式 | 取等条件 |
|:--|:-----|:-----|:---------|
| B1 | **二维形式**（高中叫法） | $(a_1b_1+a_2b_2)^2 \le (a_1^2+a_2^2)(b_1^2+b_2^2)$ | $a_1b_2=a_2b_1$（两向量共线） |
| B2 | **$n$ 维形式** | $\left(\sum_{i=1}^{n}a_ib_i\right)^2 \le \left(\sum_{i=1}^{n}a_i^2\right)\left(\sum_{i=1}^{n}b_i^2\right)$ | $a_i=\lambda b_i$（$\lambda$ 为常数，$i=1,\dots,n$） |
| B3 | **向量（内积）形式** | $\lvert\langle a,b\rangle\rvert \le \lVert a\rVert\,\lVert b\rVert$ | $a,b$ 线性相关 |
| B4 | **积分形式**（施瓦茨） | $\left(\int_a^b fg\right)^2 \le \int_a^b f^2 \cdot \int_a^b g^2$ | $f=\lambda g$（几乎处处） |

**为什么说它们是同一个**：

- B1 是 B2 在 $n=2$ 时的写法；
- 令 $a=(a_1,a_2)$、$b=(b_1,b_2)$，则 B1 左边 $=\lvert\langle a,b\rangle\rvert^2$、右边 $=\lVert a\rVert^2\lVert b\rVert^2$，开方即 B3；
- B3 与 B4 的区别只是「有限维内积空间」与「函数内积空间 $L^2$」——同一个定理换了个空间。

> 所以：**「柯西不等式」「柯西-施瓦茨不等式」「内积 ≤ 范数乘积」「范数不等式」四个叫法指同一条**。称它「范数不等式」是因为 B3 的形态看起来像范数性质，但单独的范数性质（齐次性、三角不等式）是另一组事——见 [[不等式积累]] 第三节。

## 二、两条通用用法

### 2.1 配凑平方和

B2 的使用前提是**右边是两个平方和**（或能看成两个向量的范数）。题面若给的是 $\sum a_i^2$ 与 $\sum a_i b_i$，直接套；若给的是别的东西，先**造**出平方和。

**典型一次配凑**：已知 $x,y>0$，$x+y=1$，求 $\dfrac1x+\dfrac1y$ 的下界。

$$
\frac1x+\frac1y=\left(\frac{1}{\sqrt x}\right)^2+\left(\frac{1}{\sqrt y}\right)^2
\ \ge\ \frac{\left(\frac{1}{\sqrt x}\sqrt x+\frac{1}{\sqrt y}\sqrt y\right)^2}{x+y}
=\frac{(1+1)^2}{1}=4
\qquad(\text{取等于 }x=y=\tfrac12)
$$

这一步用的是 B2 的**等价变形**（分母移项形式，即「权方和 / 柯西分式形式」）：

$$
\frac{u_1^2}{v_1}+\frac{u_2^2}{v_2} \ \ge\ \frac{(u_1+u_2)^2}{v_1+v_2}\qquad(v_i>0)
$$

> 这一条是**考研最高频的柯西用法**：见到「分式之和 + 分母之和已知」直接想它。

### 2.2 待定系数

需要的是 $\sum \alpha_i x_i$ 的界，而题面给的平方和带权（如 $\sum w_i x_i^2=C$）时，把 B2 里的 $b_i$ **故意取成含待定参数的形式**，让 $\sum b_i^2$ 与已知的加权平方和配平，再用「取等条件」反解参数。

$$
\left(\sum \alpha_i x_i\right)^2=\left(\sum \frac{\alpha_i}{\sqrt{w_i}}\cdot \sqrt{w_i}\,x_i\right)^2
\ \le\ \left(\sum \frac{\alpha_i^2}{w_i}\right)\left(\sum w_i x_i^2\right)
$$

**取等条件用来定参数**：$a_i=\lambda b_i$ 即 $\sqrt{w_i}x_i \propto \frac{\alpha_i}{\sqrt{w_i}}$，给出最优的 $x_i$。

### 2.3 微型例子

1. **分式配凑**：证 $\dfrac{a^2}{x}+\dfrac{b^2}{y}\ge\dfrac{(a+b)^2}{x+y}$（$x,y>0$）。
   关键一步：取 $u=\big(\frac{a}{\sqrt x},\frac{b}{\sqrt y}\big)$、$v=(\sqrt x,\sqrt y)$ 套 B2；或把差值写成完全平方 $\dfrac{(ay-bx)^2}{xy(x+y)}$ 直接看出非负。
2. **定系数取最值**：已知 $x^2+y^2=1$（$\mathbb{R}^2$），求 $x+2y$ 的取值范围。
   关键一步：$(x+2y)^2\le(1^2+2^2)(x^2+y^2)=5$ → $-\sqrt5\le x+2y\le\sqrt5$；取等条件 $y=2x$ 与 $x^2+y^2=1$ 联立给出 $x=\pm\frac{1}{\sqrt5}$，最值确实取得到。
3. **$n$ 维求和界**：证 $\left(\sum_{i=1}^n a_i\right)^2\le n\sum a_i^2$。
   关键一步：取 $b_i\equiv1$，右边 $=\left(\sum 1^2\right)\left(\sum a_i^2\right)=n\sum a_i^2$——这是「和 ≤ $\sqrt n$ × 平方和」这条常用放缩的来源。
4. **积分形式**：证 $\left(\int_0^1 f\right)^2\le\int_0^1 f^2$。
   关键一步：取 $g\equiv1$，B4 右边 $=\int_0^1 f^2\cdot\int_0^1 1\,dx$。

> **验算记录（2026-09-13）**：
> (1) 分式配凑——$a=1,b=2,x=0.5,y=1$（取等点）时两边同为 $6$，差值恒等式 $\frac{a^2}{x}+\frac{b^2}{y}-\frac{(a+b)^2}{x+y}=\frac{(ay-bx)^2}{xy(x+y)}$ 两边均为 $0$ ✓；非取等点 $a=1,b=2,x=y=1$：左 $5>$ 右 $4.5$ ✓。
> (2) 定系数——$x=1/\sqrt5=0.447214,\ y=2/\sqrt5=0.894427$ 时 $x+2y=2.236068=\sqrt5$，取等 ✓。
> (3) $n$ 维——$n=5$、$a_i=i$：$(\sum a_i)^2=225\le n\sum a_i^2=275$ ✓。

## 三、识别标志

| 题面出现什么 | 该想起 |
|:-------------|:-------|
| 「平方和」乘「平方和」≥「乘积和的平方」的形状 | 直接 B2 |
| **分式之和** + 分母之和为定值 | 权方和形式 $\sum\frac{u_i^2}{v_i}\ge\frac{(\sum u_i)^2}{\sum v_i}$ |
| 求 $\sum \alpha_i x_i$ 在 $\sum w_ix_i^2=C$ 下的最值 | B2 + 待定系数 + 取等条件 |
| 向量、内积、夹角、投影 | B3（$\cos\theta=\frac{\langle a,b\rangle}{\lVert a\rVert\lVert b\rVert}$ 的取值范围就是它） |
| 定积分乘积的估计 | B4 |
| $n$ 项和与平方和的大小比较 | 取 $b_i\equiv1$ 的柯西 |
| 「两个数列交错相乘再求和」 | B2（分子分母配对） |

**与均值不等式的分工**：

| 场景 | 选谁 |
|:-----|:-----|
| 和 ↔ 积（同一次数、同一组数） | **均值链** [[不等式积累]] |
| 和 ↔ 平方和（**跨次数**，两串数交错） | **柯西** |
| 求 $a+b$ 的最小值（$ab$ 已知） | 均值 |
| 求 $\sum u_i^2/v_i$ 的最小值 | 柯西（权方和） |
| 求 $kx+my$ 的最大值（$\sum x_i^2$ 已知） | 柯西 |

> 一句话切分：**均值处理「同一串数的不同平均数」，柯西处理「两串数的交错配对」。**

## 四、使用场景对照

| 题型 | 柯西形式 | 关键动作 |
|:-----|:---------|:---------|
| 分式求和最小值 | 权方和 | 把分子凑成平方，分母直接相加 |
| 线性式在球面上的最值 | B2/B3 | 待定系数 + 取等条件反解 |
| 证明数列或积分不等式 | B2/B4 | 选 $b_i$（常取 $1$ 或 $\sqrt{w_i}$）使右边变成已知量 |
| 向量模长、夹角、投影估计 | B3 | 用 $\lVert a\rVert\lVert b\rVert$ 夹住 $\lvert\langle a,b\rangle\rvert$ |
| 证明三角不等式 | B3 → 三角 | 见下节 |

## 五、与三角不等式的衔接（为什么它俩总一起出现）

**柯西能推出三角不等式**：在 B3 中取 $\lVert a+b\rVert^2$ 展开，

$$
\lVert a+b\rVert^2=\lVert a\rVert^2+2\langle a,b\rangle+\lVert b\rVert^2
\ \le\ \lVert a\rVert^2+2\lVert a\rVert\lVert b\rVert+\lVert b\rVert^2
=(\lVert a\rVert+\lVert b\rVert)^2
$$

**取等条件**：$a,b$ 同向（线性相关且系数同号）。

**所以考研题里两者常连用**：先用柯西把内积估成范数乘积，再用三角不等式把 $\lVert a+b\rVert$ 拆成 $\lVert a\rVert+\lVert b\rVert$。见 [[不等式积累]] 第三节的绝对值形式（$n=1$ 降维版）。

## 六、相关变形备查

| 变形 | 形式 | 场合 |
|:-----|:-----|:-----|
| 权方和 | $\displaystyle\sum\frac{u_i^2}{v_i}\ge\frac{\left(\sum u_i\right)^2}{\sum v_i}$（$v_i>0$） | 分式之和 |
| 带权柯西 | $\left(\sum a_ib_i\right)^2\le\left(\sum w_i a_i^2\right)\left(\sum \frac{b_i^2}{w_i}\right)$（$w_i>0$） | 加权平方和已知 |
| 赫尔德（推广） | $\sum\lvert a_ib_i\rvert \le \left(\sum\lvert a_i\rvert^p\right)^{1/p}\left(\sum\lvert b_i\rvert^q\right)^{1/q}$，$\frac1p+\frac1q=1$ | $p=q=2$ 时即柯西；**考研不要求，备查** |
